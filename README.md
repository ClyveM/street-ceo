# Street CEO

Voice-first sales, inventory, and finance for street vendors — built for the
Meta Global AI Developer Hackathon (deadline: November 4, 2026).

Demo business: a Zimbabwean tuckshop selling everyday grocery products.

## Team

11 named AI specialists coordinated by Mutungamiri (CTO). Start at
[AGENTS.md](AGENTS.md), then [tasks/master-board.md](tasks/master-board.md).

## Stack (MVP)

React + TypeScript PWA · Python FastAPI · PostgreSQL · IndexedDB offline ·
"Apo"/"Napo" voice sales · Meta-powered insights. See
[docs/architecture.md](docs/architecture.md).
